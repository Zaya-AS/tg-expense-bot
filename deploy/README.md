# Первый запуск

1. Скопируйте `.env.example` в `.env` в корне проекта. Заполните `TELEGRAM_BOT_TOKEN` и задайте уникальный `POSTGRES_PASSWORD`. Не добавляйте `.env` в Git.
2. Выполните `docker compose up -d --build`.
3. Проверьте `docker compose ps` и `docker compose logs -f bot`.
4. Отправьте боту `/start`. Он должен ответить и создать запись в таблице `users`.

При создании нового пустого тома PostgreSQL выполнит `000001_create_core_tables.up.sql`. Для уже существующего тома скрипт повторно не запускается. Для следующих изменений схемы понадобится отдельный механизм миграций; не удаляйте том ради повторного применения SQL.

Compose передаёт настройки БД контейнеру бота. `DATABASE_URL` в `.env` нужен только для запуска `go run ./cmd/api` вне Compose. Если пароль содержит `$`, заключите значение в одинарные кавычки в `.env`, чтобы Compose передал его буквально.
